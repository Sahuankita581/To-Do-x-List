# 📝 To-Do-x-List

To-Do-x-List is a simple and interactive task management web application built using **HTML, CSS, and JavaScript**.  
It helps users organize their daily tasks efficiently with a clean and user-friendly interface.

---

## 🚀 Features

- ➕ Add new tasks  
- ✏️ Edit existing tasks  
- ❌ Delete tasks  
- ✅ Mark tasks as completed  
- 💡 Simple and responsive UI  
- ⚡ Beginner-friendly project structure  

---

## 🛠️ Technologies Used

- **HTML5** – Structure of the application  
- **CSS3** – Styling and layout  
- **JavaScript (Vanilla JS)** – Logic and DOM manipulation
